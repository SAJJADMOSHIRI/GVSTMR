# Data archive

Do not commit the large manuscript ZIP archives to normal Git history.

Required manuscript archives:

- GVSTMR_FINAL_2015_2024.zip
- GVSTMR_SIMULATION_CONUS_10T_V2.zip
- GVSTMR_ANNUAL_GGPR_GEOSHAP_UNCERTAINTY_2015_2024.zip

Recommended publication workflow:

1. Keep source code on GitHub.
2. Archive the exact v1.0.0 code release and the distributable data/materials in Zenodo.
3. Add the Zenodo DOI to the root README and CITATION.cff.
